# Cloud Platform

クラウドサービスを設計・実装・運用するためのモノレポジトリです。

各サービスは、アプリケーション、インフラストラクチャ、AIコンテキストを含めた自己完結した単位として管理します。

## Philosophy

本リポジトリは、マイクロサービスとGitOpsの考え方をベースとしています。

サービスを開発・運用・デプロイの最小単位とし、サービスに必要なリソースは可能な限り同一ディレクトリに集約します。

また、Gitを唯一の信頼できる情報源（Single Source of Truth）とし、コードだけでなく、インフラストラクチャやAIコンテキストを含めたサービスの状態をGitで管理します。

## Goals

* サービス単位で自己完結した構成を実現する
* Git を唯一の信頼できる情報源（Single Source of Truth）とする
* Infrastructure as Code による再現可能な環境を構築する
* AI と協調した開発・設計・レビューを行う

## Repository Structure

```text
.
├── README.md
├── services/
│   └── <service-name>/
│       ├── app/
│       ├── infra/
│       └── .ai/
│           └── SKILL.md
└── .github/
    └── workflows/
```

## Repository Principles

* 1サービス = 1デプロイ単位
* サービスに必要なリソースは可能な限り同一ディレクトリに集約する
* 技術選定はサービスごとに行い、リポジトリ全体では特定の技術スタックを前提としない
* AIコンテキストはサービス単位で管理し、そのサービス固有の知識を保持する
